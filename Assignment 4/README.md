# Контрольные вопросы к Assignment 4
**Тема:** гибридные и распределённые параллельные вычисления

## 1. В чём заключается отличие гибридных вычислений от вычислений только на CPU или только на GPU?

Гибридные вычисления предполагают совместное использование CPU и GPU в рамках одной программы, где каждая вычислительная часть выполняется на наиболее подходящем устройстве. В отличие от вычислений только на CPU или только на GPU, гибридный подход позволяет эффективнее использовать ресурсы системы: CPU выполняет управляющую логику и последовательные операции, а GPU — массово-параллельные вычисления, что приводит к сокращению общего времени выполнения программы.

## 2. Для каких типов задач целесообразно распределять вычисления между CPU и GPU?

Распределение вычислений между CPU и GPU целесообразно для задач, которые:
- содержат как последовательные, так и параллельные этапы;
- работают с большими массивами данных;
- допускают разбиение вычислений на независимые части;
- требуют высокой вычислительной мощности при относительно простой логике.

К таким задачам относятся численные расчёты, обработка изображений, моделирование физических процессов и задачи машинного обучения.

## 3. В чём разница между синхронной и асинхронной передачей данных между CPU и GPU?

Синхронная передача данных блокирует выполнение программы до завершения копирования данных между CPU и GPU. Асинхронная передача позволяет выполнять копирование данных параллельно с вычислениями, не приостанавливая работу процессора или графического ускорителя, что требует явного управления синхронизацией.

## 4. Почему асинхронная передача данных может повысить производительность программы?

Асинхронная передача данных позволяет перекрывать вычисления и операции передачи данных. Это снижает время простоя CPU и GPU, уменьшает накладные расходы на обмен данными и, как следствие, повышает общую производительность программы.

## 5. Какие основные функции MPI используются для распределения и сбора данных между процессами?

К основным функциям MPI относятся:
- `MPI_Init` — инициализация среды MPI;
- `MPI_Comm_rank` — получение номера текущего процесса;
- `MPI_Comm_size` — получение общего числа процессов;
- `MPI_Scatter` — распределение данных между процессами;
- `MPI_Gather` — сбор данных от процессов;
- `MPI_Reduce` — агрегация данных с использованием заданной операции;
- `MPI_Finalize` — завершение работы MPI-программы.

## 6. Как количество процессов MPI влияет на время выполнения программы и почему?

С увеличением числа процессов MPI время выполнения программы может уменьшаться за счёт параллельного выполнения вычислений. Однако при дальнейшем росте числа процессов увеличиваются накладные расходы на обмен данными и синхронизацию, из-за чего ускорение становится нелинейным или может отсутствовать.

## 7. Какие факторы ограничивают масштабируемость распределённых параллельных программ?

Масштабируемость распределённых программ ограничивается следующими факторами:
- задержками и пропускной способностью сети;
- накладными расходами на обмен данными;
- необходимостью синхронизации процессов;
- неравномерным распределением нагрузки;
- наличием последовательных участков кода (закон Амдала).

## 8. В каких случаях использование распределённых вычислений оправдано, а в каких — неэффективно?

Распределённые вычисления оправданы при решении задач с большими объёмами данных и высокой вычислительной сложностью, требующих масштабирования. Они неэффективны для задач малого размера, с преобладанием последовательных операций или с интенсивным обменом данными между процессами, так как накладные расходы могут превысить выигрыш от параллелизма.
