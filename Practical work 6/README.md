## Контрольные вопросы

### 1. Какие основные типы памяти используются в OpenCL?

В OpenCL используются следующие основные типы памяти:
- **Глобальная память** — доступна всем рабочим элементам, имеет наибольшую задержку доступа и используется для хранения больших массивов данных.
- **Локальная память** — общая для рабочих элементов одной рабочей группы, имеет меньшую задержку по сравнению с глобальной памятью.
- **Приватная память** — доступна только одному рабочему элементу и используется для хранения локальных переменных.
- **Константная память** — предназначена для хранения неизменяемых данных и оптимизирована для чтения.

Выбор типа памяти напрямую влияет на производительность OpenCL-программы.

### 2. Как настроить глобальную и локальную рабочую группу?

Глобальная рабочая группа определяет общее количество рабочих элементов, которые выполняют ядро.  
Локальная рабочая группа задает количество рабочих элементов внутри одной группы.

Размеры рабочей группы настраиваются при запуске ядра с помощью параметров `global_work_size` и `local_work_size`.  
Оптимальный размер локальной группы зависит от архитектуры устройства и задачи.

### 3. Чем отличается OpenCL от CUDA?

Основное отличие заключается в переносимости:
- **OpenCL** является открытым стандартом и поддерживает различные устройства, включая CPU, GPU и ускорители от разных производителей.
- **CUDA** является проприетарной технологией NVIDIA и работает только на GPU этой компании.

Кроме того, CUDA предоставляет более тесную интеграцию с архитектурой NVIDIA, тогда как OpenCL ориентирован на универсальность.

### 4. Какие преимущества дает использование OpenCL?

Использование OpenCL позволяет:
- разрабатывать переносимые параллельные программы для различных аппаратных платформ;
- использовать вычислительные ресурсы CPU и GPU в одной программе;
- эффективно масштабировать вычисления под разные архитектуры;
- снизить зависимость от конкретного производителя оборудования.

Эти преимущества делают OpenCL удобным инструментом для кросс-платформенных параллельных вычислений.
