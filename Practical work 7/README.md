---

Целью данной практической работы является изучение и реализация параллельных алгоритмов редукции и сканирования (префиксной суммы) на графическом процессоре с использованием технологии CUDA, а также исследование производительности данных алгоритмов и способов их оптимизации.

1. Реализовать алгоритм редукции для вычисления суммы элементов массива на GPU.
2. Реализовать алгоритм сканирования (префиксной суммы) на GPU.
3. Провести анализ производительности реализованных алгоритмов.
4. Оптимизировать код с использованием различных типов памяти CUDA.

## Теоретическая часть

### 1. Редукция

Редукция представляет собой операцию, которая сводит множество входных элементов к одному результирующему значению, например, сумме, минимуму или максимуму. В контексте GPU редукция выполняется параллельно с использованием иерархии потоков и блоков. Каждый поток обрабатывает часть данных, а затем частичные результаты объединяются с использованием разделяемой памяти.

---

### 2. Сканирование (префиксная сумма)

Сканирование, или префиксная сумма, представляет собой операцию вычисления накопленного результата для каждого элемента массива. Например, для массива `[1, 2, 3, 4]` результатом сканирования будет массив `[1, 3, 6, 10]`. Данный алгоритм широко применяется в задачах обработки данных, сортировки, построения гистограмм и параллельных алгоритмах.

---

### 3. Типы памяти в CUDA

В архитектуре CUDA используются следующие основные типы памяти:

- **Глобальная память** — основная память GPU, доступная всем потокам, но обладающая высокой задержкой.
- **Разделяемая память** — быстрая память, доступная только потокам внутри одного блока, используется для оптимизации доступа к данным.
- **Локальная память** — память, выделяемая для каждого потока, обычно используется для хранения временных переменных.

## Практическая часть

### Задание 1. Реализация редукции

Для вычисления суммы элементов массива было реализовано CUDA-ядро редукции. Алгоритм основан на внутриблочной редукции с использованием разделяемой памяти. Каждый поток загружает элемент массива в разделяемую память, после чего выполняется параллельное суммирование внутри блока.

Корректность работы алгоритма проверялась путем сравнения результатов GPU-реализации с последовательной реализацией на CPU.

---

### Задание 2. Реализация префиксной суммы

Для вычисления префиксной суммы было реализовано CUDA-ядро сканирования. Алгоритм использует разделяемую память для хранения промежуточных значений и выполняет накопление значений внутри блока. Результаты GPU-реализации сравнивались с результатами последовательного вычисления на CPU.

---

### Задание 3. Анализ производительности

Для анализа производительности были проведены замеры времени выполнения редукции и сканирования на массивах различного размера:

- массив из 1024 элементов;
- массив из 1 000 000 элементов;
- массив из 10 000 000 элементов.

Измерения проводились как для GPU-реализаций, так и для последовательных CPU-алгоритмов. Полученные результаты показали, что при малых размерах массива CPU может превосходить GPU из-за накладных расходов на запуск CUDA-ядра, однако при увеличении размера массива GPU-реализация демонстрирует значительное ускорение.

В ходе оптимизации использовалась разделяемая память, что позволило сократить количество обращений к глобальной памяти и повысить производительность алгоритмов.

## Контрольные вопросы

### 1. В чём разница между редукцией и сканированием?

Редукция сводит массив элементов к одному значению, в то время как сканирование вычисляет накопленный результат для каждого элемента массива.

---

### 2. Какие типы памяти CUDA используются для оптимизации редукции и сканирования?

Для оптимизации редукции и сканирования в основном используется разделяемая память, так как она обладает низкой задержкой и высокой пропускной способностью по сравнению с глобальной памятью.

---

### 3. Как можно оптимизировать префиксную сумму на GPU?

Префиксную сумму можно оптимизировать путем использования разделяемой памяти, минимизации обращений к глобальной памяти, уменьшения числа синхронизаций и применения иерархических алгоритмов сканирования.

---

### 4. Приведите пример задачи, где применяется сканирование.

Сканирование применяется в задачах сортировки, построения гистограмм, анализа больших массивов данных, а также в алгоритмах обработки изображений и сигналов.
