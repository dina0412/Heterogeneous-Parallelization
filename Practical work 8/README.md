# Практическая работа №8  
## Разработка гибридного приложения для CPU и GPU

---

## Цель работы

Целью данной практической работы является разработка гибридного приложения, распределяющего вычисления между CPU и GPU для обработки массива данных, а также изучение принципов гибридных вычислений, передачи данных между CPU и GPU и анализа производительности.

---

## Задачи работы

1. Реализовать обработку массива данных на CPU с использованием OpenMP.
2. Реализовать обработку массива данных на GPU с использованием CUDA.
3. Организовать передачу данных между CPU и GPU.
4. Провести анализ производительности гибридного приложения.

---

## Теоретическая часть

### 1. Гибридные вычисления

Гибридные вычисления представляют собой подход, при котором вычислительные задачи распределяются между CPU и GPU для эффективного использования ресурсов системы. CPU применяется для последовательных операций и управления вычислениями, а GPU — для массово-параллельной обработки данных.

---

### 2. OpenMP

OpenMP — это API для многопоточного программирования на CPU, позволяющее эффективно распараллеливать вычисления с использованием директив компилятора. OpenMP обеспечивает простой способ использования многоядерных процессоров.

---

### 3. CUDA

CUDA — это платформа параллельных вычислений на GPU, разработанная компанией NVIDIA. CUDA позволяет запускать тысячи потоков параллельно, что делает её особенно эффективной для обработки больших массивов данных.

---

### 4. Передача данных между CPU и GPU

Передача данных между CPU и GPU осуществляется через шину PCI Express и может стать узким местом по производительности. Для повышения эффективности гибридных приложений необходимо минимизировать количество таких передач и перекрывать их с вычислениями.

---

## Практическая часть

### Задание 1. Обработка массива на CPU с использованием OpenMP

Был создан массив данных размером `N = 1 000 000`. Для обработки массива на CPU использовалась технология OpenMP. Каждый элемент массива умножался на 2. Было выполнено измерение времени обработки на CPU.

---

### Задание 2. Обработка массива на GPU с использованием CUDA

Массив данных был скопирован в память GPU. Для обработки массива было реализовано CUDA-ядро, в котором каждый поток умножал один элемент массива на 2. После завершения вычислений данные были скопированы обратно на CPU. Было измерено время выполнения обработки на GPU.

---

### Задание 3. Гибридная обработка массива

Массив был разделен на две части: первая половина обрабатывалась на CPU с использованием OpenMP, а вторая половина — на GPU с использованием CUDA. Обработка выполнялась параллельно на CPU и GPU. Было замерено общее время выполнения гибридной обработки.

---

### Задание 4. Анализ производительности

Было проведено сравнение времени выполнения обработки массива в трех режимах: CPU, GPU и гибридном.

## Анализ результатов

Результаты показывают, что при выполнении простой операции (умножение элементов массива на 2) GPU-реализация оказалась медленнее CPU-реализации. Это объясняется накладными расходами на передачу данных между CPU и GPU, а также временем запуска CUDA-ядра.

Гибридный подход показал наилучший результат, так как вычисления на CPU и GPU выполнялись параллельно. Это позволило перекрыть часть накладных расходов и более эффективно использовать вычислительные ресурсы системы.

## Выводы

1. CPU с использованием OpenMP обеспечивает хорошую производительность для простых операций и массивов среднего размера.
2. GPU-реализация эффективна при больших объемах данных и вычислительно сложных операциях.
3. Гибридный подход позволяет достичь наилучшей производительности за счет параллельного выполнения вычислений на CPU и GPU.
4. Эффективность гибридных вычислений зависит от характера задачи, объема данных и накладных расходов на передачу данных.

## Контрольные вопросы

### 1. Какие преимущества предоставляют гибридные вычисления?

Гибридные вычисления позволяют эффективно использовать ресурсы CPU и GPU, обеспечивая повышение производительности и гибкость при обработке данных.

---

### 2. Как минимизировать накладные расходы при передаче данных между CPU и GPU?

Накладные расходы можно минимизировать за счет сокращения количества передач данных, использования асинхронных операций и перекрытия передачи данных с вычислениями.

---

### 3. Какие задачи лучше выполнять на CPU, а какие — на GPU?

На CPU целесообразно выполнять задачи с последовательной логикой и управлением, а на GPU — задачи с высокой степенью параллелизма и обработкой больших массивов данных.

---

### 4. Как можно улучшить производительность гибридного приложения?

Производительность гибридного приложения можно улучшить за счет балансировки нагрузки между CPU и GPU, оптимизации использования памяти и уменьшения накладных расходов на передачу данных.
