## Контрольные вопросы

### 1. Как изменяется время выполнения программы при увеличении количества процессов? Почему?

При увеличении количества процессов время выполнения программы обычно уменьшается, поскольку вычислительная нагрузка распределяется между несколькими процессами и обрабатывается параллельно. Это позволяет быстрее выполнять операции над большими массивами данных и матрицами.

Однако при слишком большом числе процессов ускорение может замедляться или даже ухудшаться из-за роста накладных расходов на передачу данных между процессами, синхронизацию и управление вычислениями.

### 2. Какие факторы могут влиять на производительность программы?

На производительность MPI-программы влияют следующие факторы:

- размер обрабатываемых данных;
- количество процессов и равномерность распределения нагрузки;
- объем и частота обмена данными между процессами;
- задержки и пропускная способность сети;
- эффективность используемых MPI-операций (Scatter, Reduce, Bcast, Allgather и др.);
- характеристики аппаратного обеспечения (число ядер, объем памяти).

### 3. Как можно оптимизировать передачу данных между процессами?

Передачу данных между процессами можно оптимизировать следующим образом:

- уменьшать объем передаваемых данных;
- использовать коллективные операции MPI вместо большого количества точечных сообщений;
- передавать данные крупными блоками;
- обеспечивать равномерное распределение нагрузки между процессами;
- минимизировать число синхронизаций (`MPI_Barrier`).

### 4. Какие ограничения возникают при работе с большими данными?

При работе с большими данными возникают следующие ограничения:

- ограниченный объем оперативной памяти каждого узла;
- рост времени передачи данных между процессами;
- увеличение накладных расходов на синхронизацию;
- возможный дисбаланс нагрузки;
- ограничения пропускной способности сети.

Эти факторы могут снижать эффективность и масштабируемость параллельных программ.
